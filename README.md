Round 2: a photo-led broadsheet for Wednesday 18 November 2026. Six big picture-led stories carry the day — the Kerch bridge destroyed, the Gulf war widening, Nvidia's record quarter, Anthropic pricing its IPO, the Quad meeting in Manila, and Gaza facing winter — with ten more stories in a short briefs rail below. Sixteen stories in all, every headline and deck kept large enough to read at thumbnail size. The six photographs were generated for this entry and carry no baked-in text; all wording is drawn on top. The program copies the vendored image to /output/entry.png byte for byte, so both runs write identical bytes with no network.
